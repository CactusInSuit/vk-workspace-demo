# Проверка локального макета

Дата: 17.11.2026. Windows, Node.js 24, браузер приложения Codex.

## Обновление по скриншоту

Тёмная оболочка и главная страница «Проектов» проверены визуально при размере 1704 × 899: левая панель 60 px, карточки по 686 px, координаты первых карточек x=192/890, y=149. Высота верхнего ряда около 300 px, нижнего около 406 px, промежуток 12 px. Начало координат — область сайта без панелей Chrome. Итоговое превью: `preview-projects.jpg`.

После этой проверки доступный браузерный инструмент сменился, а новый не смог подключиться к службе браузера. Дополнительная проверка переходов в новой оболочке не завершена. Сборка и проверки модели выполняются локально. Сверка невидимых на снимке экранов Доски с оригиналом не проводилась.

## Автоматические проверки

- `npm run build` — production-сборка Vite.
- `npm test` — 9 проверок: перенос с учётом блокировки, независимость копий, библиотечные фильтры и корзина, границы холста, JSON-перенос задач/таблиц/линий, отклонение неподдерживаемых объектов, нормализация некорректных числовых полей, сохранность резервной копии, экранирование текста SVG.

## Проверено в интерфейсе

- Библиотека и редактор при desktop-размере 1440 × 900.
- Открытие доски, двойной щелчок и ввод текста, сохранение после перезагрузки.
- Отмена и повтор правок; создание стикера и рисунка.
- Перенос стикера и изменение размера, проверка изменения координат и размеров в DOM.
- Создание таблицы и изменение ячейки.
- Добавление комментария, режим презентации, настройки плотности и видимости сервисов.
- Раздел «Задачи» показывает три демонстрационные задачи с доски.
- Выгрузка SVG и PNG через штатный интерфейс; SVG прочитан XML-парсером, PNG создан и проверен визуально.
- Импорт JSON через системный выбор файла; импортированная проверочная доска перемещена в корзину.
- Загрузка изображения на доску в готовой production-сборке; временное вложение отменено.
- Узкий экран 390 × 844: ширина содержимого совпала с шириной окна, горизонтального переполнения страницы нет.
- Запуск, остановка и повторный запуск готового локального сервера. Повторный запуск использует тот же процесс; главная страница возвращает HTTP 200.
- В консоли браузера после итоговой проверки ошибок не обнаружено.

Проверки интерфейса выполнялись на демонстрационных данных. Временные изменения объектов отменены. Проверка не устанавливает полное совпадение с закрытым оригиналом VK или корректность каждого возможного сочетания действий. Ограничения макетных сервисов описаны в README.


## Опросы на доске

- `npm test`: 23 проверки, включая одно голосование на участника, замену и отзыв ответа, проценты для множественного выбора, запрет повторного ответа в викторине, закрытие по времени, импорт/резервные копии и безопасный SVG.
- В браузере проверены создание карточки из кнопки над холстом и панели инструментов, несколько ответов, просмотр участников, отзыв голоса, сохранение после перезагрузки, неправильный ответ с пояснением и перемещение за заголовок.
- Голоса принадлежат локальному идентификатору браузера. Анонимные бюллетени не содержат имени; открытые показывают имя профиля. Это автономный макет, без сетевой синхронизации голосов.
- За основу взяты основные режимы [опросов Telegram](https://telegram.org/blog/polls-2-0-vmq), а не интеграция с Telegram.
