# Инструкции для всех задач проекта

## Синхронизация WorkSpace с GitHub

- При каждом нововведении в нашей версии WorkSpace обновляй соответствующую версию в репозитории GitHub: https://github.com/CactusInSuit/vk-workspace-demo.
- После реализации проверь изменения, создай коммит с понятным описанием и отправь его в соответствующую ветку GitHub. Это постоянное разрешение пользователя на такую синхронизацию; отдельное подтверждение для каждого обновления не требуется.
- Перед завершением задачи проверь, что отправленный коммит присутствует в удалённой ветке. В итоговом ответе укажи результат синхронизации.
- Если отправка недоступна или завершилась ошибкой, сохрани локальные изменения и явно сообщи, что GitHub ещё не обновлён, с указанием причины. Не сообщай об успешной синхронизации без проверки.
- Не включай в коммит посторонние изменения, секреты и локальные служебные файлы. Не перезаписывай чужие изменения и не используй принудительную отправку.

Эти правила действуют для всех задач, работающих с этой папкой проекта и её подпапками.
