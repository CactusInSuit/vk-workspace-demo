# Локальный макет VK WorkSpace

Редактируемый прототип оболочки WorkSpace и Доски для подготовки презентаций. Тёмная оболочка и главная страница «Проектов» воспроизведены по предоставленному пользователем скриншоту от 17.11.2026: названия сервисов, навигация, векторные пиктограммы, цвета, размеры и расположение карточек. Доска восстановлена по публичным описаниям VK. Оригинальные закрытые исходники недоступны; точное совпадение экранов, которых нет на скриншоте, не подтверждено.

## Запуск

Дважды нажмите **«Запустить WorkSpace.cmd»**. Готовая сборка откроется по адресу **http://127.0.0.1:4173/**. Для запуска нужен установленный Node.js 22 или новее. На этом компьютере запуск проверен с Node.js 24. Сетевое подключение к VK не требуется. Сервер слушает только этот компьютер.

Повторный запуск использует уже работающий экземпляр. Статическая сборка находится в `dist/`; для её запуска не нужны `npm install` и папка `node_modules`.

Чтобы остановить сервер, запустите **«Остановить WorkSpace.cmd»**. Доски останутся в браузере. Перед переходом к разработке также остановите сервер этим файлом.

## Что работает

- Общая оболочка: тёмная тема, переключение сервисов, меню приложений, профиль, поиск досок. Стартовый экран — «Проекты».
- «Проекты»: вкладки «Главная», «Задачи», «Страницы», «Дашборды», «Заявки»; карточки «Пространства», «Уведомления», «Избранное», «Мои задачи». Имена пространств и дата повторяют эталонный кадр. Доступны поиск и добавление пространства.
- Опросы на холсте: отдельная перемещаемая карточка, 2–12 вариантов, анонимный или открытый режим, несколько ответов, викторина с пояснением, отзыв голоса, скрытые результаты и ручное/автоматическое завершение. Создание — кнопка «Опрос» над холстом или в панели инструментов. Опросы и ответы сохраняются в браузере и резервных копиях.
- Библиотека: команды, шаблоны, поиск, сортировка, плитки и список, избранное, дублирование, переименование, перемещение, корзина и восстановление.
- Доска: стикеры, текст, прямоугольники, эллипсы, ромбы, стрелки, рисование, выделитель, ластик, таблицы, фреймы, карточки задач, изображения, комментарии и реакции.
- Выбор нескольких объектов через Shift или рамкой, перенос, изменение размера, цвета, текста, обводки и блокировки; отмена, повтор, копирование и дублирование.
- Перемещение холста, масштаб, мини-карта, поиск объектов, разные фоны, локальные сохранённые версии и презентация по фреймам.
- Задачи с досок видны в разделе «Задачи». Макет мессенджера и календаря содержит переход на доску.
- Инструмент «ИИ → задачи» позволяет выделить область с печатным или рукописным текстом, изображениями и стикерами, при желании добавить голосовую запись, проверить распознанные поля и создать карточки задач. Для реального распознавания добавьте API-ключ DeepSeek в настройках профиля; ключ хранится отдельно в localStorage и не экспортируется.
- JSON для переноса редактируемой доски, SVG и PNG для иллюстраций, печать для сохранения PDF. Резервная копия всего пространства находится в настройках макета.

## Как вносить изменения

1. **Текст и объекты:** откройте доску, дважды нажмите на объект. В верхней панели выделенного объекта меняются цвет, размер текста и другие свойства. Кнопка с ползунками открывает точные координаты и параметры задачи или таблицы.
2. **Оформление пространства:** аватар внизу слева → «Настройки макета». Можно менять название, профиль, основной цвет и набор сервисов. Пиктограммы общей оболочки находятся в `WorkspaceChrome.jsx`, точные стили эталона — в `reference.css`.
3. **Новые интерфейсы и механики:** меняйте исходники или опишите нужное изменение в этом чате. Основные точки расширения перечислены в [архитектуре](docs/ARCHITECTURE.md).

Клавиши: `V` — выбор, `H` — рука, `N` — стикер, `T` — текст, `R` — фигура, `P` — фломастер, `A` — стрелка, `F` — фрейм. Пробел с перетаскиванием двигает холст. Ctrl с колесом меняет масштаб. `Ctrl+Z` и `Ctrl+Shift+Z` отменяют и повторяют; `Ctrl+C/V/D` копируют, вставляют и дублируют; Delete удаляет выбранное.

## Данные и границы макета

Доски автоматически сохраняются в localStorage текущего браузера для адреса `http://127.0.0.1:4173`. Другой браузер, другой адрес или очистка данных сайта создают отдельное пространство. Перед важным показом скачайте резервную копию. Восстановление резервной копии **добавляет** доски к существующим. Изображения сжимаются до 1400 пикселей по большей стороне; доступный объём хранения зависит от браузера.

Сетевой совместной работы, реальной отправки сообщений, авторизации, почты, звонков и подключения к данным VK нет. Настройки общего доступа показывают интерфейс, но не создают сетевые права; ссылка работает только с данными того же браузера. PDF-файлы представлены карточками вложений без загрузки содержимого и просмотра. Сессия выбора лучших идей работает локально до закрытия доски; отдельные карточки опросов сохраняют ответы после перезагрузки. Мессенджер и календарь содержат демонстрационные данные; остальные второстепенные сервисы подготовлены как экраны для расширения. Стрелки не привязываются автоматически к фигурам; фреймы пока перемещаются отдельно от содержимого.

## Разработка

```powershell
npm ci
npm run dev
```

Откройте http://127.0.0.1:4173/. Перед запуском разработки остановите готовый локальный сервер, если он занимает этот порт. Сборка: `npm run build`. Проверки: `npm test`. После изменения исходников пересоберите `dist/`, чтобы обновить обычный запуск.

Подробности: [архитектура и источники](docs/ARCHITECTURE.md), [проверки и ограничения](docs/VALIDATION.md).
